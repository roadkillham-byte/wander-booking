# Dashboard pages: Same again and Refer a team

**Spec:** `~/Projects/wander-dashboard-design/docs/superpowers/specs/2026-11-13-client-dashboard-design.md` (section 6: existing clients see "Same again, [date]"; referral plan Task 8: the "Refer a team" screen).
**Contract:** `docs/contract.md`. Change it first, then the fixtures, then the code.

## Global Constraints

- The page never computes a price. Prices, fees and 4-Pack numbers are read from the store.
- Client-facing copy says "we", never "Sam". Sentence case. No "deposit". No invented urgency.
- A referrer sees a referred client's first name only.
- Every request ends on a plain screen, never an error.
- Tests: `node --test` for pure modules; the journey check is `SHOTS=/tmp node test/flow.mjs` (headless, 360 px).

## Review Focus

- A client with a held or confirmed booking never sees "Same again". A client with no completed booking never sees it either.
- The "Same again" date is never in the past and never inside 24 hours.
- Referral data in a session belongs to that client only: another client's referrals never appear.
